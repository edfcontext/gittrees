GitTrees currently bundles no third-party code, models or package dependencies.

External tools and system frameworks

GitTrees invokes your installed Git and, for GitHub features, the GitHub CLI. These executables are not included in the app bundle. Their licenses and notices accompany their own distributions:
Git: https://git-scm.com/about/free-and-open-source
GitHub CLI: https://github.com/cli/cli/blob/trunk/LICENSE

SwiftUI, AppKit, Foundation and Foundation Models are supplied by Apple.

Semgrep Community Edition
Optional, separately installed security scanner: https://semgrep.dev
Semgrep is not bundled with GitTrees. The baseline rules included with GitTrees are first-party rules, not a redistributed Semgrep Registry rule pack.
